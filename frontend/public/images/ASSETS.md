# Visual assets

- `pulse-sculpture.webp`: original generated artwork for Pulseflare, optimized to approximately 100 KB. The source render is retained outside the deployable public directory.
- Slack, Discord, and Telegram SVGs: Simple Icons v11, distributed under CC0, retrieved from the official `simple-icons` npm package via jsDelivr. Brand marks identify integrations; they do not imply endorsement or customers. See https://github.com/simple-icons/simple-icons/blob/11.0.0/LICENSE.md.
- Interface icons: Lucide (ISC), supplied by the existing `lucide-react` dependency.
- Geist and Geist Mono: self-hosted via Fontsource packages (SIL Open Font License).
